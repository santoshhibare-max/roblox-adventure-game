# Roblox Adventure Game

An immersive adventure game featuring parkour puzzles, combat mechanics, and NPC rescue missions.

## Game Overview

- **Player Role**: Prince/Princess returning to save the castle
- **Start Zone**: Concrete baseplate with spawn point
- **Parkour Section**: Navigate puzzles to earn random unlock codes
- **Locked Area**: Use codes to access restricted zones
- **Combat Zone**: Parallel world creatures attacking the castle
- **Objective**: Rescue the King, Queen, and Princess (or reverse roles)

## Game Progression

1. Spawn at baseplate
2. Complete parkour challenges
3. Obtain random unlock code
4. Unlock restricted area
5. Find key to portal
6. Get upgraded
7. Purchase gun and ammo
8. Battle creatures
9. Rescue NPCs
10. Save the castle
